Keywords für Ihre Website prüfen

Suchbegriffe für eine Kundenwebsite anhand von Suchvolumen, Klickpreis und Anzeigenwettbewerb beurteilen.

Auftrag für den AgentenAktueller Katalog
{{MODE_NOTE}}{{TASK_STATUS}}

{{KEYWORD_METRICS_PRICE}} USDC · pro Abfrage

Eine Keyword-Metrics-Abfrage für Ihre ausgewählten Begriffe und ein Land. Beginnen Sie mit einer kurzen Liste; das Eingabelimit steht im aktuellen Katalog.

Das erhalten Sie

Eine Tabelle je Suchbegriff mit verfügbarem monatlichem Suchvolumen, Klickpreis und Anzeigenwettbewerb. Damit kann eine Agentur Begriffe für ein Seitenbriefing auswählen.

Verkürztes Muster zur Veranschaulichung. Erfundenes Beispiel; keine Live-Abfrage und kein gekauftes Ergebnis.

Suchbegriff | Monatliche Suchen | Klickpreis | Anzeigenwettbewerb
Beispielleistung | 320 | 1,40 USD | MITTEL

Nachfrage auf Landesebene, keine Stadtrankings. Anzeigenwettbewerb ist keine organische SEO-Schwierigkeit. Fehlende Werte bleiben unbekannt; Suchvolumen beweist keine Kaufnachfrage.

Vorbereiten, dann entscheiden

  1. Eingabe festlegen und Verfügbarkeit im kostenlosen Katalog prüfen.
  2. Kostenlose Eingabeprüfung nutzen. Vor Freigabe genauen Preis, Währung, Netzwerk und Empfänger prüfen. Ein unbezahltes HTTP 402 ist ein Preisangebot.
  3. Eine Abfrage und ein Ausgabenlimit freigeben. Ein bezahlter Aufruf benötigt einen passenden x402-Käufer.

Beispieleingabe – kostenlose Prüfung

POST {{BASE_URL}}/api/v1/preflight/keyword-metrics
Content-Type: application/json

{
  "keywords": [

  ],
  "location_code": 2276,
  "language_code": "de"
}
